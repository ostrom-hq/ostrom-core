# Compatibility vectors

`vectors/` is a copy of `mvp/compat/vectors/` of the TypeScript prototype (repository `ostrom`, branch
`feat/compat-vectors`, commit `b4a0e923`), generated by `mvp/compat/generate.ts` from the prototype's real routes. The
format they pin (canonical JSON v1, receipt signature field, subject preimages, package envelope) is described in that
directory's README; the Kotlin tests of `receipts/` replay them byte for byte.

- `vectors/neutral/`: test key, 12 canonical-form cases, 9 signed receipts.
- `vectors/private/`: a signed session package envelope and a workflow receipt with its bundle. The package's `files`
  order is the prototype's locale order; the Kotlin compiler will sort by code units (decision of 30/10/2026), so these
  vectors are only used to verify signatures on exact bytes, never as golden compiler output.
- `extra/js-numbers.json`: 4 060 doubles and the text ECMAScript writes for each, from `extra/js-numbers.mjs` (Node).

A vector that changes is a format change: replace these files only on purpose, and in every implementation.

The test key is derived from a public seed and signs nothing but these vectors.
